# Dataset cards

No dataset is bundled or downloaded automatically. Before adding data, create one card per dataset recording its source and version, license/access terms, permitted use, label definitions, patient/site identifiers available, split strategy, class counts, exclusions, demographic coverage and limitations. Verify public access conditions directly with each dataset provider. Do not assume NIH ChestX-ray14, CheXpert, TB collections, EyePACS or APTOS are interchangeable or freely redistributable.
